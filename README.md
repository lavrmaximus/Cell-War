# Cell War

**Cell War** — это пошаговая стратегическая игра, вдохновленная классическими играми на бумаге. Основные механики включают захват территорий, управление экономикой и тактические бои. Проект поддерживает несколько режимов: одиночная игра против ИИ, hot-seat мультиплеер на одном устройстве и полноценный онлайн-мультиплеер.

## Технологический стек

- **Фронтенд**: React 18, TypeScript, Tailwind CSS v4.
- **Бэкенд**: Python, Flask.
- **База данных**: PostgreSQL (планируется для онлайн-режима).
- **Сборка**: Webpack (через react-scripts), PostCSS.

## Архитектура

Проект разделен на два независимых модуля:

1.  **`frontend`**: Клиентское приложение (SPA) на React. Отвечает за UI, рендеринг игрового поля и взаимодействие с пользователем.
2.  **`backend`**: Серверное приложение на Flask. Отвечает за игровую логику, валидацию ходов и (в будущем) мультиплеер.

## Установка и запуск

Проект настроен так, что основные команды можно выполнять из корневой директории.

### Предварительные требования

*   **Node.js** (рекомендуется v16+)
*   **Python** (3.8+)

### 1. Установка зависимостей

**Фронтенд:**
Выполните команду в корне проекта:
```bash
npm run install-frontend
```
*Или вручную: `cd frontend && npm install`*

**Бэкенд:**
Зависимости бэкенда устанавливаются автоматически при первом запуске скрипта `npm run backend`.

### 2. Запуск приложения

**Запуск Фронтенда:**
```bash
npm start
```
Эта команда запустит React-приложение в режиме разработки. Откройте [http://localhost:3000](http://localhost:3000) в браузере.

**Запуск Бэкенда:**
```bash
npm run backend
```
Эта команда:
1.  Создаст виртуальное окружение (`backend/venv`), если его нет.
2.  Установит необходимые библиотеки из `requirements.txt`.
3.  Запустит Flask-сервер.

## Разработка

### Работа с CSS (Tailwind)
Проект использует **Tailwind CSS v4**. Конфигурация находится в `frontend/postcss.config.js` и `frontend/tailwind.config.js`.
Для корректной работы стилей используется пакет `@tailwindcss/postcss`.

### Добавление новых зависимостей
*   Для фронтенда: перейдите в папку `frontend` (`cd frontend`) и используйте `npm install <package>`.
*   Для бэкенда: добавьте пакет в `backend/requirements.txt`.
